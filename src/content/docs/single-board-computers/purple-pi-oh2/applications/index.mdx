The Purple Pi OH2 can host containerised services, visual automation flows,
computer-vision tools, robotics middleware, and a home-automation platform. These
guides use the board's Debian or Ubuntu environment and assume terminal access.

<Callout variant="warning" title="Draft documentation">
  These procedures are adapted from Elephantronics' Purple Pi OH2 documentation
  and have not been independently verified for this wiki. Check package names and
  versions against your OS image.
</Callout>

## Before you start

- A Purple Pi OH2 with network access.
- SSH or local terminal access.
- A user that can run `sudo`.
- Enough free storage for Docker images, OpenCV packages, and ROS 2.

Some guides depend on Docker. Install Docker first if you plan to use Home
Assistant, and verify it with `docker run hello-world` before continuing.
