OpenCV is an open-source computer-vision library used for image processing, video
analysis, and vision-based applications. On the Purple Pi OH2 it can be combined
with the camera interfaces or with the NPU demos.

## Update the system

```bash
sudo apt update
```

## Install OpenCV and dependencies

```bash title="Python, codecs, and GStreamer"
sudo apt install python3-pil python3-numpy python3-pip git wget at-spi2-core
sudo apt install libavcodec-dev libavformat-dev libswscale-dev
sudo apt install libgstreamer-plugins-base1.0-dev libgstreamer1.0-dev
sudo apt install python3-opencv libopencv-dev
```

The source document repeated the last `apt install` line; it only needs to run
once.

## Verify the installation

```bash
python3 -c "import cv2; print(cv2.__version__)"
```

A version such as `4.x.x` should print without errors.

<Callout variant="note" title="Camera pipeline">
  The distribution OpenCV package may use GStreamer for camera capture depending
  on how it was built. If `cv2.VideoCapture()` cannot open a MIPI camera, check
  the GStreamer pipeline and the camera device node first.
</Callout>

## Troubleshooting

| Issue | Check |
| --- | --- |
| `ModuleNotFoundError: cv2` | Install `python3-opencv`; make sure you are using the system Python or the same virtual environment |
| Version command fails | Re-run `sudo apt update` and inspect the apt error |
| Camera opens but returns no frames | Check the device node and GStreamer plugins |
| GUI window cannot open | Run over SSH with X forwarding or use a local display |
