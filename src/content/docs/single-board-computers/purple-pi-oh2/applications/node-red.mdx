Node-RED is a flow-based development tool for visual programming. On the Purple
Pi OH2 it can connect GPIO, network services, MQTT brokers, and HTTP APIs without
writing a full application for every experiment.

## Install Node-RED

The Node-RED project provides an official installer script that installs Node.js,
Node-RED, and the required dependencies:

```bash title="Run the official installer"
bash <(curl -sL https://raw.githubusercontent.com/node-red/linux-installers/master/deb/update-nodejs-and-nodered)
```

The download and installation can take several minutes.

## Installation prompts

The source guide recommends these answers:

| Prompt | Recommended answer |
| --- | --- |
| Node-RED settings file | Press `Enter` for the default |
| Share anonymous usage information | `No` |
| User security | `No` for a local test; enable it before exposing the editor |
| Projects feature | `No` |
| Flow file | `flows.json` |
| Encrypt credentials file | Press `Enter` to skip |
| Editor theme/style | Default |
| Text editor component | `Monaco` |
| Allow external modules in function nodes | `Yes` |

<Callout variant="warning" title="Do not expose an unauthenticated editor">
  Choosing “No” for user security leaves the editor open to anyone who can reach
  port 1880. Enable authentication, or bind the service to localhost and use an
  SSH tunnel, before exposing the board to a network.
</Callout>

## Control Node-RED

| Task | Command |
| --- | --- |
| Start | `node-red-start` |
| Stop | `node-red-stop` |
| Restart | `node-red-restart` |
| View logs | `node-red-log` |
| Enable at boot | `sudo systemctl enable nodered.service` |
| Disable at boot | `sudo systemctl disable nodered.service` |

## Open the editor

On the board itself:

```text
http://localhost:1880
```

From another computer on the same network:

```text
http://<purple-pi-ip-address>:1880
```

Replace `<purple-pi-ip-address>` with the board's address, for example
`192.168.1.100`.

## Troubleshooting

| Issue | Check |
| --- | --- |
| `node-red-start` not found | The installer did not finish; rerun it and read the output |
| Editor unreachable | Check `node-red-log`, the board IP, and whether port 1880 is listening |
| Node.js version error | Re-run the official installer so Node.js and Node-RED match |
| Flow lost after reboot | Confirm the flow file path and that `nodered.service` is enabled |
