The Purple Pi OH2 can act as a bridge between field devices and higher-level
software. This section covers three common industrial protocols:

- **Modbus RTU** over an RS-485 transceiver connected to UART7.
- **MQTT** with a Mosquitto broker for publish/subscribe messaging.
- **CAN bus** with an MCP2515 controller connected to SPI0.

<Callout variant="warning" title="Draft documentation">
  The procedures are adapted from Elephantronics' Purple Pi OH2 documentation and
  have not been independently verified for this wiki. RS-485 and CAN wiring
  mistakes can damage transceivers; check polarity, supply voltage, and
  termination before powering the bus.
</Callout>

## Common prerequisites

- A Purple Pi OH2 with a Debian or Ubuntu image.
- SSH or local terminal access.
- Python 3 and a virtual environment for the example scripts.
- The specific transceiver or controller module described on each page.
