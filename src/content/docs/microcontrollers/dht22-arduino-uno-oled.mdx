The DHT22 (also sold as the AM2302) is a digital temperature and humidity sensor.
It sends calibrated readings over a single data line, so the microcontroller does
not need to measure an analog voltage. This tutorial connects a three-pin DHT22
module and a 0.96-inch I2C OLED to an Arduino UNO and displays the readings.

## The DHT22 sensor

The DHT22 combines a temperature-sensing element, a humidity-sensing element, and
a small controller in one package. The controller converts the measurements into
a digital signal, which means the Arduino reads a value rather than calibrating an
analog voltage.

Typical datasheet figures for the DHT22 family are a temperature range of about
−40 °C to 80 °C and a relative-humidity range of about 0–100% RH. Treat those as
family-level figures and confirm the exact part on your module's datasheet.

## DHT22 module pinout

The three-pin module used in this tutorial has VCC, DATA, and GND. The data line is
a single-wire digital interface; the Arduino library handles the timing.

## How the DHT22 communicates

When the microcontroller requests a reading, the DHT22 responds on its DATA line
with a 40-bit message: humidity and temperature values plus a checksum byte. The
Arduino library decodes that message and returns floating-point values.

Because the protocol is timing-sensitive, use a library rather than bit-banging
the data line. The DHT22 family is also relatively slow; the source sketch waits
about two seconds between readings.

## The sketch

Create a new sketch, paste the code below, and select the correct board and port
under **Tools**. The sketch is reproduced from the source article with comments
added to make the example pin map explicit.

```cpp title="dht22_oled.ino"
#include <Wire.h>
#include "DHT.h"
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

// Example pin map for an Arduino UNO R3:
// DHT22 DATA -> D2, OLED SDA -> A4, SCL -> A5.
// Verify the pin order on your modules before powering up.
#define DHTPIN 2
#define DHTTYPE DHT22

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);
DHT dht(DHTPIN, DHTTYPE);

float Temperature;
float Humidity;
float Temp_Fahrenheit;

void setup() {
  Serial.begin(115200);

  // Start the DHT22
  dht.begin();

  // Start the OLED. 0x3C is common; some modules use 0x3D.
  if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println("OLED initialization failed!");
    while (1);
  }

  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);

  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("DHT22 Sensor");
  display.println("Initializing...");
  display.display();

  delay(2000);
}

void loop() {
  Humidity = dht.readHumidity();
  Temperature = dht.readTemperature();
  Temp_Fahrenheit = dht.readTemperature(true);

  // Check whether the readings are valid
  if (isnan(Humidity) || isnan(Temperature) || isnan(Temp_Fahrenheit)) {
    Serial.println("Failed to read from DHT22 sensor!");

    display.clearDisplay();
    display.setTextSize(1);
    display.setCursor(0, 0);
    display.println("DHT22 Sensor");
    display.println();
    display.println("Sensor Error!");
    display.display();

    delay(2000);
    return;
  }

  // Print readings to the Serial Monitor
  Serial.print("Humidity: ");
  Serial.print(Humidity);
  Serial.print("%  ");
  Serial.print("Temperature: ");
  Serial.print(Temperature);
  Serial.print(" C  ");
  Serial.print(Temp_Fahrenheit);
  Serial.println(" F");

  // Update the OLED
  display.clearDisplay();

  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("Temperature:");

  display.setTextSize(2);
  display.setCursor(0, 12);
  display.print(Temperature, 1);

  display.setTextSize(1);
  display.print(" C");

  display.setTextSize(1);
  display.setCursor(0, 38);
  display.println("Humidity:");

  display.setTextSize(2);
  display.setCursor(0, 49);
  display.print(Humidity, 1);

  display.setTextSize(1);
  display.print(" %");

  display.display();

  // The DHT22 should not be read continuously
  delay(2000);
}
```

## What the code does

- **Pin and sensor type.** `DHTPIN 2` and `DHTTYPE DHT22` must match the wiring
  and the sensor you actually have. A DHT11 will not work correctly with the
  DHT22 type selected.
- **Display setup.** The `Adafruit_SSD1306` object is given the 128 × 64
  resolution, the `Wire` I2C bus, and the display address. The `-1` argument
  tells the library there is no separate reset pin.
- **Start-up check.** If `display.begin()` returns false, the sketch prints a
  message and stops. That is deliberate: there is no point continuing without a
  display.
- **Error handling.** `isnan()` catches failed reads instead of displaying
  meaningless numbers.
- **Slow polling.** The two-second delay keeps the sensor within its comfortable
  sampling range and makes the display readable.

## Check the output

Open **Tools → Serial Monitor** and set the baud rate to **115200**. The source
article shows output similar to this:

```text
Humidity: 62.4%  Temperature: 27.3 C  81.1 F
Humidity: 62.7%  Temperature: 27.4 C  81.3 F
Humidity: 63.0%  Temperature: 27.4 C  81.3 F
```

These numbers are illustrative, not expected values. Your readings depend on the
room, the sensor, and its calibration.

A successful build should show:

1. "DHT22 Sensor / Initializing..." on the OLED after reset.
2. Temperature and humidity values updating about every two seconds.
3. Matching lines in the Serial Monitor.
4. No repeated "Sensor Error!" message.

## If it does not work

| Symptom | First checks |
| --- | --- |
| OLED stays blank | VCC and GND; SDA/SCL not swapped; I2C address 0x3C versus 0x3D |
| "OLED initialization failed!" | I2C wiring, display address, and that A4/A5 are the correct pins on your board |
| "Failed to read from DHT22 sensor!" | DATA wire on D2, module power, and the pull-up requirement for a bare sensor |
| Serial Monitor is empty | Correct port selected, baud rate 115200, and a USB data cable |
| Readings show `nan` | The library could not obtain a valid frame; check DATA, power, and polling interval |
| Values drift or look implausible | Let the sensor settle after power-up and keep it away from heat sources; compare with a known reference |

For a broader routine, see [Troubleshooting](/troubleshooting/).

## DHT22 vs DHT11

If you are choosing between the two sensors, the DHT22 generally offers a wider
range and better resolution. The trade-offs are qualitative in the source article:

| Feature | DHT11 | DHT22 |
| --- | --- | --- |
| Temperature range | More limited | Wider |
| Humidity range | More limited | Wider |
| Resolution | Lower | Higher |
| Measurement speed | Faster | Slower |
| Accuracy | Lower | Better |
| Cost | Lower | Higher |

For projects where measurement quality matters more than cost, the DHT22 is
usually the better choice. Confirm the exact figures in the datasheet for the part
you buy.
